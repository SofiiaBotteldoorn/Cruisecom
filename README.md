Dit is een objectgeoriënteerde C#-applicatie waarin cruisegegevens worden beheerd: schepen, personeel, maatschappijen en berekeningen van cruiseprijzen.

Features:

- Abstracte klassen en polymorfisme voor bemanning
- Realistische certificaten en rangvalidatie
- LINQ-berekeningen voor personeels- en schipkosten
- Exception handling via custom RangException
- Console-uitvoer met nette structuur en overzicht

Technologieën:
- C#
- Objectgeoriënteerd programmeren (OOP)
- LINQ, encapsulatie, exception handling
